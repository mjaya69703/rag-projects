# Hallmark Audit — RAG SPA (app/static) — 2026-08-06

Target: `app/static/index.html` · `app/static/styles.css` · `app/static/tokens.css` · `app/static/app.js`
Mode: audit → implement punch list (redesign in-place, IA dipertahankan: Workbench chat app).

Struktur: sidebar (sessions + documents) + chat region + floating composer — makrostruktur *Workbench*,
tepat untuk aplikasi chat, BUKAN template landing AI. Tidak ada stamp `/* Hallmark */` di CSS (log.json
menunjukkan 08-02 Cobalt/Workbench, 08-03 Coral/Index-First). Token system sudah rapi (OKLCH, satu accent
cool-blue, Manrope + DM Mono). Yang perlu dibereskan: icon system, token leakage, XSS, dan beberapa tell.

---

## CRITICAL

1. **XSS — markdown via innerHTML tanpa sanitasi** · `app.js` `renderMarkdown()` + `createMessage()` +
   `askQuestion()` (delta re-render) · Fix: sanitasi semua HTML yang dirender dari jawaban LLM
   (DOMPurify via CDN, konsisten dengan marked/hljs). User message sudah aman (textContent).
2. **Tidak ada Content-Security-Policy / SRI** · `index.html` (marked.js, highlight.js, Google Fonts dari CDN) ·
   Fix: tambahkan DOMPurify (bagian dari fix #1) + opsional `integrity`/CSP header sederhana.

## MAJOR

3. **Emoji-as-icon-system** · index.html (✨📚📌💡📥🚀🔍💬🌓) + app.js (⚡🤖, ⌫ ✎ ☰ ✕ ✆ dll.) ·
   "Generic emoji as feature icon" + "Mismatched icon sets". Fix: satu set ikon inline-SVG (stroke 1.5,
   round caps, 24 viewBox, currentColor) untuk: brand mark, chat baru, unggah, contoh, file, cari, tema,
   hapus, edit, menu, tutup, plus, chevron, panah kirim, cache note.
4. **Inline OKLCH di luar token** · `styles.css` L~307-311 (`.message-text pre` bg/color/border =
   oklch(16%/95%/28%)) + `.modal::backdrop` oklch(0% 0 0 / .5) · "Mid-render token improvisation".
   Fix: angkat ke tokens.css: `--color-code-bg`, `--color-code-ink`, `--color-code-border`, `--backdrop`.
5. **Side-stripe card** · `styles.css` `.source-card { border-left: 3px solid var(--color-accent) }` ·
   "The side-stripe card" (tell 2018-SaaS-AI). Fix: hairline border semua sisi + aksen berupa dot/ikon
   kecil, atau tanpa stripe sama sekali.
6. **Emoji sebagai ilustrasi fitur** · `.empty-icon` 📚 3.5rem + tombol "📌 Unggah PDF" "💡 Coba pertanyaan" ·
   Fix: ganti dengan ikon SVG / biarkan typography memimpin.
7. **Brand mark sparkle ✨** · index.html `<span class="brand-mark">✨</span>` + gradient tile ·
   Fix: mark SVG custom sederhana (mis. monogram atau mark abstrak), gradient 2-stop accent→accent-hover
   dipertahankan hanya jika halus — atau flat.

## MINOR

8. **`transition: all`** · styles.css `.session-button, .document-button`, `.icon-button`, `.file-drop` ·
   Fix: sebut properti (background-color, transform, border-color).
9. **Colored glow shadows** · `.new-chat/.button/.send-button` box-shadow color-mix accent ·
   Fix: di dark theme ini jadi "shadow-glow on dark" — pakai elevasi lightness (surface lebih terang =
   lebih tinggi) atau shadow ketat + gelap.
10. **Celebratory toast + confirm untuk aksi terlihat** · app.js `showToast('Nama chat diperbarui.')`,
    `confirm()` untuk delete · Fix: silent success; delete session = modal konfirmasi (destructive,
    irreversible) — pertahankan; hapus toast sukses yang berlebihan.
11. **Eyebrows** ("RAG WORKSPACE", "PERSONAL RETRIEVAL ENGINE", "INGESTION DOKUMEN", "AKSI CEPAT") ·
    diterima sebagai label aplikasi (bukan penomoran tic) — batasi, jangan tambah baru.
12. **Google Fonts via CDN tanpa fallback kuat** · offline → system-ui · Minor: pertimbangkan self-host
    atau terima fallback (personal LAN tool). Jangan blokir.

Count: **2 critical · 5 major · 6 minor** (per audit verb, tell di atas bernama dari anti-patterns.md)
